# 实验验证结论：哪些方案效果更好？

> 时间：2026-09-03 ~ 09-07 ｜ baseline = hoshi 权威原版（评分8 / 第15天止损）
> 检验纪律：统一一套参数跑全部窗口（防单窗口调参过拟合）+ 失真审计 + 随机窗口 out-of-sample 复测

## 二、失真审计（关键裁决）

- **S4 / hard5_S4 不可采信 ❌**：核查其 Top 盈利单出现创业板单日 +39.5%（300299）、+39.0%（300815）——**超过 ±20% 涨停上限**。根因 = "立即武装 + 峰值回落止盈"假设能以接近当日最高价成交，未建模涨跌停，实盘不可实现。数值虚高，一律不用。
- **hard5_score9 审计通过 ✅**：对节点1/节点4 检测"疑似超单日涨停上限的盈利单" = **0 笔**。数值可信。

## 三、随机窗口 out-of-sample 复测（防过拟合，种子 20260903 可复现）

随机抽 2010 年后 5 个窗口（按月粒度、1~5 年、可重叠，与原 5 节点重叠度低）：

| 窗口 | baseline% | hard5_score9% | 跑赢? |
|---|---|---|---|
| W1 2019-12~2022-04 | −13.98 | **+12.72** | YES |
| W2 2013-04~2017-08 | +73.58 | +33.24 | no |
| W3 2014-12~2018-05 | +41.72 | **+45.22** | YES |
| W4 2017-05~2019-07 | +2.74 | **+10.92** | YES |
| W5 2019-06~2022-02 | +7.46 | **+21.84** | YES |
| **合计** | +111.53% | **+123.94%** | — |

- **0/5 反转（5 窗口全正）**、4/5 跑赢 baseline；唯一跑输的 W2 是 2013-17 超级大牛（仍 +33% 高正收益）。
- **本质 = 削峰填谷的防守型稳健**：baseline 巨亏窗口被扭正（W1：−13.98% → +12.72%），代价是牛市让出部分超额。

## 四、为什么 hard5_score9 更好（机制拆解）

1. **hard5（硬止损提前到第 5 天）**：原版前 14 天对 −30%~−50% 的深亏完全裸奔；hard5 让深套票在第 5~14 天就能被 −8.2% 硬止损割掉，砍掉最毒的尾部亏损（节点4 从 −11.29% → +59.08% 的主力贡献）。
2. **score9（评分门槛 8→9）**：只在亏损窗口提供部分保护，但**在牛市系统性误杀赚钱的低分信号**（2012-15 被挡掉的 score∈[8,9) 批次净赚 +24.2 万，而保留的高分批次只赚 +5.85 万）。它不是收益来源，是过滤器。
3. 两者叠加产生非线性协同（单独都不惊艳：hard5 节点4 −8.07%、score9 节点4 +0.74%，叠加 +59.08%），经随机窗口复测确认非巧合。

## 五、最终结论（按用途选择）

| 用途 | 推荐方案 | 理由 |
|---|---|---|
| **实盘主策略（稳健优先）** | **hard5_score9**：MIN_SCORE=9.0 + LOSS_HARD_START_DAY=5，其余同原版 | 两套独立检验 5+5 窗口全正、累加更高、审计 0 失真 |
| 实盘（吃满牛市 beta、能忍受回撤） | baseline 原版 | 大牛窗口(2012-15/2013-17)收益最高 +73%~+60%，但亏损窗口 −8%~−14% |
| ⛔ 任何情况 | S4 / hard5_S4 | 未建模涨跌停的虚高，实盘不可实现 |

## 六、遗留风险提示
- 引擎未建模涨跌停：评估任何"高换手/立即武装/追涨停"类策略前必须先补涨跌停模型，否则数值不可信。
- 引擎纯 Python 逐日全市场扫描（load 50s + 单节点 2~5 分钟）；向量化改造可提速 5~10 倍（见阶段报告第八节）。
