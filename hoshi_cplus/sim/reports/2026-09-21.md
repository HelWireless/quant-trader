# 晚间收盘复核（21:30 自动化）

## 🚨 先报一个数据事故：日线库被"盘中快照"污染了

复核收盘价时发现 **09-18 和 09-21 两天的 K 线是盘中快照，不是收盘价**。

根因在 `scripts/refresh_tdx_duckdb.py` 的 `upsert_symbol`：

```python
new_bars = [b for b in bars if (max_date is None or b["date"] > max_date)]
if not new_bars:
    return 0        # ← 该票已有当日行 → 直接跳过，永不修正
```

只要**当天盘中跑过一次刷新**，当天那根 K 线就被永久冻结成当时的 O/H/L/C，
收盘后再跑刷新**也不会覆盖**。`append_new_bars.py` 同为 append-only，失真值一路进了 CSV。
