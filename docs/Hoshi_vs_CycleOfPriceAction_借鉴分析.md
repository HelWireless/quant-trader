# Hoshi vs Cycle of Price Action —— 借鉴点分析

> 目的：把 `docs/CycleOfPriceAction_A股移植.md`（Kell 价格行为周期框架的 A 股提炼）与
> 项目唯一现役策略 Hoshi（权威最终版，见 `.workbuddy/hoshi_qmt_kit/.../hoshi_final_strategy.md`）
> 做机制级对比，找出 **Cycle 哪些机制能补 Hoshi 已知死结、怎么补、要不要补**。
>
> 重要纪律：本文是**分析 + 建议**，不是"照搬移植"。凡是 Hoshi 已验证过同类思路且被否决的，
> 文中明确标「⚠️ Hoshi 已验否决」，避免重复踩坑。
> 整理日期：2026-09-03

---

## 0. 一句话结论

Hoshi 和 Cycle 是**两种哲学**：
- Hoshi =「**抄底接反弹**」：上升趋势里连跌企稳买进，赌反弹。本质是**均值回归 / beta 博弈**。
- Cycle =「**顺势动量 + 周期分层**」：只在周期上升段买突破/回踩，用位置感管仓位。本质是**趋势跟踪 + regime 分层**。

**两者不是谁取代谁，而是互补。** Cycle 真正值得借鉴的，不是它的买卖信号，
而是它「**先大盘分层定仓位、后个股周期定买卖**」的分层择时骨架——这正好打在 Hoshi
所有已知死结的同一个病灶上：**Hoshi 缺少"该不该满仓做"的主动环境闸门**。

| **加仓** | ❌ 无（一次性买入，最多同买 10 只）| ✅ 金字塔分批（突破首仓→回踩加→基底再加）| ⭐ Hoshi 缺分批建仓 |

## 2. 用 Cycle 对照 Hoshi 的三个已知死结

### 死结①：止损太晚 → 深套票裸奔到 -30~-50% 才反弹割肉

**现状**（已实证）：Hoshi 第 15 天才开始监控止损，前 14 天完全裸奔。
任何窗口「止损(反弹卖出)」累计亏损都达 -44万~-68万，深亏单(<-25%)每窗口 3–10 笔，
是磨平收益的头号元凶。

**Cycle 的做法**：初始止损（5–8%）从入场就生效 + **结构止损（破基底低点/破 EMA20）** +
**10 日时间止损**（未脱离成本就释放资金）。

**借鉴评估**：
- ⚠️ 固定提前止损 = Hoshi 方向 B / regime 实验，**已 5 窗口 + 2026 真实窗口否决**——提前止损会误杀「该让跑」的反弹盈利票。不能照搬「早止损」。
- ✅ **但 Cycle 的「结构止损」给了新角度**：Hoshi 现在只在「价格跌破成本百分比」时止损，
  从没试过「**收盘跌破买入时那波反弹的基线/前期低点**」这类结构位。这跟 Hoshi 记忆里
  「末跌加速确认(C)是真实信号质量线索」相呼应——**结构位可能比固定%更能区分"真破位"和"正常回踩"**。
  → 值得作为**新假设**验证，但必须多窗口 + 2026 真实窗把关（见第 4 节建议）。

### 死结②：缺少「该不该满仓做」的主动环境闸门

**现状**：Hoshi 只有 R3（亏 25% 才停手，**滞后**）和广度门控（MA60，**滞后约 13 天**）。
2026-06 后 regime 实验也因 MA60 滞后把反弹市误判成弱市。**没有"此刻处于攻/慎/防"的主动判断**。

**Cycle 的做法**：创指 + 沪深300 双指数 vs MA20（快）+ MA20 斜率 → 直接给「仓位上限」四档，
**在开仓之前**就用环境决定「今天能做多满」，而不是亏了才被动刹车。

**借鉴评估**：⭐⭐ **这是最值得移植的一层**。
- Cycle 用 **MA20 而非 MA60** 判环境——比 Hoshi 现在的广度门控(MA60)反应快，**正好绕开 Hoshi regime 实验失败的滞后根因**。
- 但 ⚠️ Hoshi 已验：仓位**连续调节**（好时全仓、坏时打折）11 段全输，根因是"卡位效应"（打折也占 10 只名额）。
  → 所以**不能照搬 Cycle 的"仓位随环境打折"**，只能借用它的「**环境分档 → 挡掉整日/整段开仓**」二元闸门思路，
  且阈值要用 Hoshi 自己的多窗口验证。**方向 = 一个比 R3 更快、比 MA60 更灵敏的「环境开仓闸门」**。

### 死结③：止盈一刀切，缺「部分止盈 + 延伸计数」，盈利过度依赖个别大牛单

**现状**：Hoshi 移动止盈只有「峰值回落 1.2%」一档。实证显示**盈利窗口全靠 ≥17 笔大牛单(+20%)**，
亏窗口只有 ≤14 笔就盖不住止损。**大牛单跑不充分 + 平庸票又占着名额** 是结构弱点。

**Cycle 的做法**：
- **5R 部分止盈**：盈利到 5×初始风险就减 1/3——**先落袋一部分，再让剩余奔跑**。
- **BIAS10 延伸计数**：第 2 次乖离延伸减仓 1/3，第 3 次清大部分——**用"涨过头"信号主动兑现**。

**借鉴评估**：⭐⭐ **值得研究的第二大借鉴点**。
- Hoshi 现在是「要么全持有到峰值回落 1.2%、要么第 25 天死线」——**没有"中途分批兑现、剩余让跑"**。
  → 「先减 1/3 锁定，剩下的继续跟移动止盈」理论上能让 Hoshi 在保住大牛单的前提下、少吐回撤。
- 需数据验证：Hoshi 收益高度集中在少数大牛单，**部分止盈会不会砍掉大牛单的后续涨幅**（2015 大牛窗口 +60% 主要靠个别票持续跑）。必须在含大牛的窗口专门测。

## 3. 明确「不能借鉴」的部分（避免白费功夫）

| Cycle 元素 | 为什么不能搬 | 备注 |
|-----------|------------|------|
| **加仓/分批建仓** | Hoshi 是「满仓梭哈式」抄底，当日同买多只是**设计如此**（企稳日一次性布局），非缺陷 | 若要引入加仓，等于重写 Hoshi 入场哲学，风险极高 |
| **持仓核心化（前 3–5 重仓）** | Hoshi 10% 上限是**大哥拍板保留的保守分散**，避免单票黑天鹅 | 方向已被验证为「放大器」非「更优」 |
| **仓位随环境打折** | 已验 11 段全输（卡位效应）| ⚠️ Hoshi 明确否决 |
| **5R 止盈公式** | R=初始风险，Hoshi 入场无固定初始风险定义 | 需先给 Hoshi 定义"R"，否则无法套用 |
| **941% / 高集中度重仓** | 单年、小资金、极端行情、不可复制 | 文档自己都否了 |
| **BIAS10 固定阈值(8-15%)** | 板块/个股波动差异大 | 需用个股历史分位数，成本高 |

## 4. 建议：三个「值得立项的新假设」（按性价比排序）

每个都必须走 Hoshi 自己的多窗口 + 2026 真实窗验证纪律，防过拟合。

### 假设 A：环境开仓闸门改用「指数 MA20 快信号」
> **靶向死结②**。把广度门控/R3 前面的「要不要今天开新仓」从 MA60(慢) 换成
> **创指/沪深300 收盘 vs MA20 + MA20 斜率**（Cycle 第 1 层精简版），只在「防守/极防」档整体禁开新仓。
> 验证：2016-21、2022-25、2024-26 等亏窗口是否被前置拦截，同时 2026 反弹市不误杀。

### 假设 B：部分止盈「先减 1/3，剩余继续移动止盈」
> **靶向死结③**。在现有 S3/S4 移动止盈基础上，加一道「盈利到某阈值(如 +15~20%)先落 1/3，
> 剩 2/3 继续跟 1.2% 峰值回落」。专门在**含大牛窗口（节点2 2012-15、节点5 2023-26）**验证会不会砍掉大牛后续。

### 假设 C：结构位止损「收盘破本波反弹基线/入场前平台」
> **靶向死结①**。用 Cycle 的「破结构位」替代纯固定 % 的止损触发，
> 测试能否把深套到 -30~-50% 的票提前到更合理的结构破位就走。**需非常小心**——结构止损对 Hoshi
> 的「正常回踩后再反弹」可能同样误杀，验证门槛最高。

## 5. 结论

1. **Cycle 不是要替代 Hoshi**——Hoshi 是 beta 博弈、Cycle 是动量分层，机制本就不同，混搭要谨慎。
2. **最值得借鉴的是「分层择时骨架」**，尤其是「环境闸门用快一点的 MA20 + 档位」补上 Hoshi
   缺的「主动决定做多满」，和「部分止盈先落袋再让跑」补上「大牛单依赖」。
3. **Hoshi 之前否决的三条路（限买/提前止损/regime自适应）不能因为 Cycle 复活**——Cycle 确实主张
   「早止损 + 让票跑」，但 Hoshi 已验证这是 trade-off 而非免费午餐。要用 Cycle 的**新机制形态**
   （结构位、部分止盈、MA20 快闸门）而不是复刻它已经否掉的固定参数形态。
4. **落地前提**：以上三条都是**新假设**，必须先写成可回测脚本、用 Hoshi 自己的 csv_long 数据 +
   多窗口 + 2026 真实窗跑出证据再决定，不轻信单窗口漂亮数字。
