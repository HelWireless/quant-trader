# Cycle of Price Action — A 股可用部分提炼

> 来源：Oliver Kell（2020 U.S. Investing Championship 股票组冠军，+941.1%）在 TraderLion 提出的「价格行为周期」框架
> 提炼目标：把这套美股动量/成长股框架中，**A 股可用（尤其择时）的部分**抽出来，参数化到可回测
> 整理日期：2026-09-03

---

## 0. 一句话结论

这套框架真正值钱的**不是 941%**，而是两件事：

1. **它是一个「位置感」框架** —— 告诉你当前价格处在趋势周期的哪一段，而不是预测明天涨跌。
2. **它的择时是分层的** —— 先看大盘环境决定「能不能做」，再看个股周期决定「买不买/卖不卖」。

对 A 股而言，**第 2 点（分层择时）几乎可以直接移植**，而「做空下跌阶段」必须整段放弃。

## 1. 原框架速览

### 1.1 八阶段周期

| # | 阶段 | 价格/均线行为 | 交易动作 |
|---|------|--------------|---------|
| 1 | **Reversal Extension** | 恐慌抛售，价格远离均线，放量；低周期超跌后急速拉回均线 | 观察，不买。等价格「收紧」 |
| 2 | **Wedge Pop** | 首次反弹收复均线；价格与均线收敛形成枢轴，放量突破短期阻力 | **第一个低风险入场点** |
| 3 | **EMA Crossback** | 回踩均线获支撑，缩量止跌 | **加仓点**（第二入场） |
| 4 | **Base n' Break** | 横盘数周让均线跟上，形成紧基底后突破；低点抬高 | **加仓 + 移动止盈上移** |
| 5 | **Exhaustion Extension** | 情绪亢奋，价格大幅偏离均线（日线+周线同时） | **止盈区** |
| 6 | **Wedge Drop** | 价格收敛后放量跌破均线 | **离场 / 转防御** |
| 7 | **EMA Crossback Downside** | 下跌中首次反弹，遇均线阻力回落 | 空仓 / 做空 |
| 8 | **Base n' Break Downside** | 下跌中继，均线转为阻力 | 空仓 / 做空 |

> 循环：阶段 8 之后回到阶段 1（Reversal Extension），周而复始。

### 1.2 核心参数（Kell 实际使用）

| 项目 | 参数 |
|------|------|
| 均线系统 | **10 / 20 日 EMA**（中期趋势）；50 / 200 日 SMA（长期趋势） |
| 时间框架 | 周线看大局 → 日线管仓位 → 小时/15 分钟择时入场 |
| 初始止损 | **约 3%**（未建完仓时容忍更大波动） |
| 持仓数量 | 6–12 只，前 3–5 只为核心重仓 |
| 风险回报比 | 至少 **1:3**；单笔风险约 2% 本金 |
| 加仓方式 | 金字塔式，用浮盈加仓并上移止损 |
| 止盈规则 | 数 **extension 次数**：第 1 次可持有，**第 2 次偏离 10EMA 是止盈区**；日线+周线同时延伸 = confluence，必须减 |
| 部分止盈 | 盈利达 **5R**（5 倍初始风险）时分批减仓 |
| 大盘过滤 | **QQQ 跌破 20 EMA → 转防御**（提高现金、不用杠杆、更挑剔） |
| 胜率容忍 | 可低于 50% 仍复利（靠大 R 倍数） |

## 2. A 股移植的硬约束（必须先认清）

这 5 条决定了「哪些能抄、哪些必须改」：

| 约束 | 影响 | 应对 |
|------|------|------|
| **T+1** | 买入当日不能卖。日内冲高被套无法止损 | 入场精度要求更高；**优先尾盘入场**；止损只能次日执行 |
| **涨跌停板** | 主板 ±10%，创业板/科创板 ±20%。涨停**买不进**，跌停**卖不出** | 突破策略可能踏空或无法止损；回测必须建模，否则严重失真 |
| **做空受限** | 融券成本高、券源少，散户基本不可做空 | 周期 6/7/8 阶段**只能空仓规避，不能做空获利** |
| **散户主导 + 高换手** | 情绪周期更极端，波动更大，假突破更多 | 止损需放宽；成交量确认更重要；情绪指标更有效 |
| **政策市 + 题材轮动** | 板块效应极强，个股脱离板块难走远 | 增加**板块维度**过滤（板块指数站上 MA20 且领涨） |

> ⚠️ 最容易被忽略的一点：**A 股的涨停板制度反而提供了美股没有的「情绪量化工具」**（涨停家数、连板高度、炸板率），这是移植时**可以增强原框架**的地方。

## 3. 择时体系（核心）

分四层，从上到下逐层过滤。**上一层不通过，下一层就不用看。**

```
第 1 层  大盘环境择时   →  决定「能不能做」（仓位上限）
   ↓ 通过
第 2 层  个股周期择时   →  决定「买不买 / 卖不卖」
   ↓ 通过
第 3 层  入场时机择时   →  决定「哪一天、哪个点位买」
   ↓ 持有
第 4 层  出场时机择时   →  决定「何时止盈/止损」
```

---

### 3.1 第 1 层：大盘环境择时（最高价值，几乎可直接移植）

Kell 用 `QQQ < 20EMA → 防御`。A 股改造版：

**主过滤器（指数趋势状态）**

用**创业板指（399006）+ 沪深300（000300）**双指数（分别代表成长/权重风格）：

| 状态 | 判定条件 | 仓位上限 | 动作 |
|------|---------|---------|------|
| 🟢 **进攻** | 指数 > MA20 且 MA20 上行 | 80–100% | 正常执行突破策略 |
| 🟡 **谨慎** | 指数在 MA20 上下震荡，或 MA20 走平 | 30–50% | 只做最强主线，降低加仓频率 |
| 🔴 **防御** | 指数 < MA20 且 MA20 下行 | 0–20% | 停止新开仓，只减不加 |
| ⛔ **极端防御** | 指数 < MA60 且 MA20 < MA60（死叉） | 0% | 空仓，等周期重置 |

**辅助情绪指标（A 股独有增强）**

| 指标 | 含义 | 参考阈值 |
|------|------|---------|
| 涨停家数 | 市场赚钱效应 | > 80 家情绪高涨；< 20 家冰点 |
| 最高连板高度 | 情绪周期位置 | 5 板以上=主升；2 板以下=退潮 |
| 炸板率 | 追高风险 | 炸板率 > 40% = 高风险 |
| 两市成交额 | 增量资金 | 持续放量=趋势健康；缩量上涨=警惕 |
| 创新高家数占比 | 市场宽度 | > 10% 健康；< 2% 脆弱 |

> 💡 **A 股增强点**：Kell 只有 QQQ 一个过滤器；A 股可以用「指数趋势 + 情绪指标」双重确认，比原版更稳健。

### 3.2 第 2 层：个股周期择时（八阶段 → A 股映射）

| 原阶段 | A 股可用性 | A 股量化判定 | 动作 |
|--------|-----------|-------------|------|
| 1 Reversal Extension | ⚠️ 部分可用 | 长下影 + 放量 + 收盘拉回；BIAS10 处于近 250 日 5 分位以下 | **观察**，加入观察池不买 |
| 2 Wedge Pop | ✅ **高价值** | 收盘上穿 EMA20；EMA10 上穿 EMA20；成交量 > 5 日均量 1.5 倍 | **首仓**（30–50%） |
| 3 EMA Crossback | ✅ **高价值** | 回踩 EMA10/EMA20 不破（收盘价未跌破），回踩缩量 | **加仓**（30%） |
| 4 Base n' Break | ✅ **高价值** | 横盘 ≥ 5 日且振幅收敛（近 5 日最高/最低 < 1.12）；突破平台高点放量 | **加仓**（20–40%） |
| 5 Exhaustion Extension | ✅ **高价值（止盈）** | BIAS10 > 动态阈值；或连续放量长上影。日线+周线同时达标 = confluence | **分批止盈** |
| 6 Wedge Drop | ✅ **可用（离场）** | 收盘跌破 EMA20 且放量 | **清仓**（不做空） |
| 7 EMA Crossback Downside | ❌ 做空不可用 | — | **空仓，加入观察池** |
| 8 Base n' Break Downside | ❌ 做空不可用 | — | **空仓，等回到阶段 1** |

**关键适配：乖离率（BIAS）替代「extension」**

Kell 靠肉眼数「偏离 10EMA 的次数」，A 股可量化为 **BIAS10**：

```
BIAS10 = (Close - EMA10) / EMA10 × 100%

延伸事件计数：
  BIAS10 从 < 阈值 上穿至 > 阈值，再回落至 < 阈值  →  记为 1 次延伸

  第 1 次延伸：持有
  第 2 次延伸：减仓 1/3 ~ 1/2  ★ 止盈区
  第 3 次延伸：清大部分仓位（趋势极晚期）
```

**阈值建议（起始值，需回测校准）**

| 标的类型 | BIAS10 延伸阈值 | 说明 |
|---------|----------------|------|
| 主板（±10%） | 8% – 10% | 波动较小 |
| 创业板/科创板（±20%） | 12% – 15% | 波动更大 |
| **通用稳健做法** | **个股过去 250 日 BIAS10 的 90 分位数** | 自适应，推荐 |

> 💡 用**分位数**而非固定值，可以避免不同波动率个股的阈值失真，这是比原版更好的做法。

### 3.3 第 3 层：入场时机择时（T+1 专属适配）

Kell 用小时/15 分钟图择时 —— **A 股 T+1 下这个做法会害死你**（日内买了不能卖）。改造如下：

**✅ 推荐：尾盘确认入场**

```
信号日（突破日）→ 不在盘中追
→ 14:30–14:50 检查：
    · 当日收盘价仍站在突破位上方（未冲高回落）
    · 成交量 ≥ 5 日均量 × 1.5（放量确认）
    · 未封涨停（涨停买不进 / 次日溢价不确定）
→ 尾盘买入
```

**理由**：T+1 下当日无法止损，尾盘入场可以**看完当日全部走势再决策**，把「早盘追高被套且无法出逃」的风险降到最低。

**涨停板处理规则**

| 情形 | 处理 |
|------|------|
| 突破日**一字板/封死涨停** | **放弃本次突破**，等回踩或次日（避免买不进 / 追高次日闷杀）|
| 突破日**盘中涨停后打开（炸板）** | 视为**衰竭信号**，不买或减仓 |
| 突破日涨幅 7–9% 未封板 | 可正常尾盘买入，但仓位减半（已消耗部分空间）|

**分批建仓（适配 T+1）**

```
首仓 1/2   →  突破日尾盘（阶段 2 / Wedge Pop）
加仓 1/4   →  回踩 EMA10/EMA20 不破（阶段 3）
加仓 1/4   →  基底再突破（阶段 4）
每次加仓后，将整体止损上移至加仓成本下方
```

### 3.4 第 4 层：出场时机择时

**止损（Kell 用 3%，A 股需放宽）**

| 类型 | 规则 | 说明 |
|------|------|------|
| 初始止损 | **5% – 8%**（主板 5–6%，创业板/科创板 7–8%）| A 股波动大于美股，3% 会被日常噪音扫损 |
| 结构止损 | 收盘价跌破 **基底低点** 或跌破 **EMA20** | 更推荐，比固定百分比更贴合结构 |
| 时间止损 | 入场后 **10 个交易日**未脱离成本区 | 释放资金，避免假突破占用仓位 |
| 硬止损 | 大盘转 🔴 防御 | 无条件降仓，不看个股 |

> ⚠️ **跌停风险**：止损只能次日执行，遇跌停可能连续无法卖出。**回避有停牌/退市风险/连续一字板炒作的标的**，这是 T+1 下的生存底线。

**止盈（三层递进）**

```
第 1 层  5R 部分止盈   盈利 = 5 × 初始风险  →  减 1/3
第 2 层  BIAS 延伸止盈  第 2 次 BIAS10 延伸   →  再减 1/3
第 3 层  结构离场      收盘跌破 EMA20 / 出现 Wedge Drop → 清仓

移动止盈：趋势健康时，止损随「更高的低点」上移（EMA10 → EMA20）
```

**核心纪律**：*「周期初期要有耐心持有，周期后期要快速兑现。」* —— Kell

## 4. 完整规则表（可直接编码）

```
【选股池】
  · 剔除 ST / *ST / 退市整理
  · 上市满 60 个交易日（有足够数据）
  · 近 20 日日均成交额 > 5000 万（流动性）
  · 相对强度 RPS(60) ≥ 80（强于 80% 个股）
  · 所属板块指数 > MA20 且板块近 20 日涨幅排名前 30%
  · 基本面（可选增强）：营收同比 > 25%，净利同比 > 25%

【择时 - 大盘】
  创业板指 或 沪深300 处于 🟢/🟡 状态才允许开新仓

【买入信号】满足其一
  A. Wedge Pop：  收盘上穿 EMA20 且 EMA10 上穿 EMA20 且 量 > 1.5×5日均量
  B. EMA Crossback：回踩 EMA10/EMA20 不破（收盘未跌破）且回踩缩量
  C. Base n' Break：横盘 ≥5日 且 振幅收敛 且 突破平台高点 且 放量

  下单：信号日 14:30–14:50 执行；涨停/一字板跳过

【卖出信号】满足其一
  A. 止损：        收盘价 < 成本 × (1 - 止损%)  或  收盘跌破基底低点
  B. 时间止损：    持有 10 日未脱离成本
  C. 5R 止盈：     盈利 ≥ 5 × 初始风险 → 减 1/3
  D. 延伸止盈：    第 2 次 BIAS10 延伸 → 减 1/3
  E. 结构离场：    收盘跌破 EMA20（放量）→ 清仓
  F. 大盘防御：    指数转 🔴 → 全组合降仓

【仓位管理】
  · 单笔风险 ≤ 总资金 2%
  · 持仓 5–10 只（A 股适配 Kell 的 6–12）
  · 前 3–5 只为核心仓
  · 大盘状态决定总仓位上限（见 3.1 表）
```

## 5. 必须改造或放弃的部分

| 原框架内容 | 处理 | 原因 |
|-----------|------|------|
| 阶段 6/7/8 的**做空** | ❌ 放弃 | A 股融券受限，散户不可行 |
| 小时/15 分钟**日内择时** | 🔄 改为尾盘日线择时 | T+1 无法日内止损 |
| **3% 止损** | 🔄 放宽至 5–8% 或结构止损 | A 股波动率更高，3% 易被噪音扫损 |
| **QQQ 20EMA 过滤** | 🔄 改为 A 股指数 + 情绪指标多重过滤 | 标的与制度不同 |
| **941% 收益预期** | ❌ 完全放弃 | 单年、小资金、极端行情、高集中度，不可复制 |
| 高集中度重仓（前 3–5 只占大头）| ⚠️ 谨慎 | A 股个股黑天鹅（财务造假、监管问询）更频繁 |

### 6.2 信号生成核心逻辑（伪代码）

```python
def cycle_stage(df, i):
    """标注第 i 日处于周期哪个阶段"""
    ema10 = df['ema10'][i]
    ema20 = df['ema20'][i]
    ema20_prev = df['ema20'][i-1]
    bias10 = df['bias10'][i]
    vol_ratio = df['vol'][i] / df['vol_ma5'][i]

    uptrend = ema10 > ema20 and ema20 > ema20_prev

    if not uptrend and df['close'][i] < ema20 and vol_ratio > 1.2:
        return 'WEDGE_DROP'          # 阶段 6 → 清仓
    if not uptrend:
        return 'DOWNTREND'           # 阶段 7/8 → 空仓
    if bias10 > bias_threshold(df, i):
        return 'EXHAUSTION'          # 阶段 5 → 止盈
    if breakout_base(df, i):
        return 'BASE_N_BREAK'        # 阶段 4 → 加仓
    if pullback_to_ema(df, i):
        return 'EMA_CROSSBACK'       # 阶段 3 → 加仓
    if reclaim_ema(df, i):
        return 'WEDGE_POP'           # 阶段 2 → 首仓
    return 'HOLD_OR_WAIT'
```

### 6.3 ⚠️ 回测数据陷阱（本项目血泪教训）

在 `data/tdx.duckdb` 上回测时**必须先做代码段白名单过滤**，否则结果会严重失真：

- `raw_kline_daily` **混有大量非股票品种**：沪市指数 `sh000xxx`、深市指数 `sz399xxx`、
  沪基金 ETF `sh5xxxxx`、深基金 ETF `sz15/16/18xxxx`、北交所 `bj*`、
  **国债逆回购 `sh204xxx` / `sz1318xx`**、债券。
- **国债逆回购是隐形杀手**：`sh204003`(GC003) 的「价格」是**年化利率**（如 145.50 = 14.55%），
  当股价用会算出**约 −99% 的假暴跌**，能把一年期回测从 +20% 拖成 −15%。

**必须只保留以下代码段**（白名单，不是黑名单）：
```
sh600 / sh601 / sh603 / sh605 / sh688 / sh689
sz000 / sz001 / sz002 / sz003 / sz300 / sz301
```
参考实现：`scripts/export_hoshi_csv.py:_is_excluded()`

### 6.4 回测必须建模的 A 股细节

| 项目 | 说明 |
|------|------|
| **涨跌停** | 涨停日不能买入、跌停日不能卖出 —— **必须建模，否则收益虚高** |
| **T+1** | 买入当日不可卖出 |
| **停牌** | 跳过停牌日，不做前复权失真处理 |
| **交易成本** | 佣金（双边）+ 印花税（卖出 0.05%）+ 滑点（建议 0.1–0.2%）|
| **幸存者偏差** | 用**当时已上市的全部股票**，不能用「当前还在市的股票」回测 |

- [ ] 参数（BIAS 阈值、止损幅度、横盘天数）用的是**样本外**或滚动窗口校准
- [ ] 样本覆盖至少 **1 个完整牛熊周期**（建议 2018–2025）
- [ ] 对比基准：沪深300 / 创业板指 买入持有
- [ ] 观察指标：年化、最大回撤、夏普、胜率、盈亏比、**交易次数**（次数过少说明过拟合）

> ⚠️ 特别提醒：如果回测出现「年化 > 100% 且最大回撤 < 10%」，**先怀疑是涨跌停没建模或用了未来数据**，而不是庆祝。

## 8. 风险提示

1. **941% 不可复制** —— 那是单年、小资金组别、2020 疫情极端行情 + 重仓 Livongo/Tesla/Peloton/Spotify 的结果。Kell 本人后续年份为 +80%(2023)、+60%(2024)、+50%(2025)，这才是更现实的锚。
2. **这是主观交易框架，不是量化圣杯** —— 原框架依赖肉眼判读「收紧」「放量」，量化必然损失信息。
3. **A 股适配参数是建议起始值，不是最优值** —— 必须用你的数据实盘级回测校准。
4. **止损在 T+1 + 跌停下会失效** —— 这是系统性风险，只能靠「回避垃圾标的 + 控制仓位」缓解，无法靠策略消除。
