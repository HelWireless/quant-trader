## 五、但要泼三盆冷水

### 1. 尾部风险并没有改善

| | 现用 p6 | 方案 B |
|---|---:|---:|
| 最差窗口 | **-6.38%** | -6.85% |
| 负收益窗口 | **12 / 90** | 13 / 90 |

几乎打平，B 的负收益窗口甚至多一个。
这与《方案 B》文档「最差窗从 -27.70% 改善到 -8.75%」的说法**不一致** —— 那份报告的对比基准是
**原版（score 8、R3 开）**，而这里的基准 p6 本身已经带了 score 9 + 第 5 天硬止损，尾部早已被压过一轮。
**B 相对 p6 不再提供额外的尾部保护。**

### 2. 换手翻 2.8 倍，而滑点没建模

- 90 窗总交易：p6 **9,380 笔** vs B **26,349 笔**（2.81 倍）。
- 回测已扣佣金 0.025%（最低 5 元）、印花税 0.05%、过户费 0.001%，但 **没有建模滑点**。
- 本策略主要交易**超跌小盘股**，冲击成本明显。B 多出的 ~17,000 笔交易每笔多滑一点，
  实盘侵蚀会明显大于 p6。**B 的 +58.7% 是上限，不是承诺。**

### 3. 窗口高度重叠，t 值被高估

30 个随机起点里有多个落进同一段行情（例如 5 个窗口起点都在 2015-03 前后），90 个窗口**不是独立样本**。
真正可信的是**符号检验**（不假设分布、不受厚尾影响）：**69 胜 21 负，p < 1e-6**，方向性结论成立；
但「平均 +34.30pp」这个幅度要打折看。

## 六、2×2 消融：差异到底来自哪里

p6 与 B 之间有**两个**参数不同（硬止损 -6.0/-8.2、R3 开/关），所以又跑了另外两个组合，
凑成完整的 2×2，把因素拆开（同一批 90 窗口、同种子）：

| | R3 **开** | R3 **关** |
|---|---|---|
| 止损 **-6.0%** | **p6**（现用） | **C**（新组合） |
| 止损 **-8.2%** | A | **B**（方案B） |

| 配置 | 几何收益 | 中位收益 | 90窗期末资金合计 | 平均回撤 | 总笔数 |
|---|---:|---:|---:|---:|---:|
| p6 (-6.0 · R3开) ← 现用 | 22.27% | 16.48% | 33,598,531 | **-10.97%** | 9,380 |
| A (-8.2 · R3开) | 14.65% | 13.70% | 31,469,554 | -13.05% | 9,246 |
| **C (-6.0 · R3关) ← 最优** | **61.20%** | **71.29%** | **46,329,702** | -15.06% | 27,291 |
| B (-8.2 · R3关) ← 方案B | 50.39% | 59.61% | 42,858,280 | -17.49% | 26,349 |

### 因素分解（配对，90 窗）

| 改动 | 在 R3 开时 | 在 R3 关时 | 平均效应 | 显著性 |
|---|---:|---:|---:|---|
| 止损 -6.0% → -8.2% | **-7.89pp** | **-12.86pp** | **-10.37pp** | t=-6.09/-8.04，胜率仅 19/90、8/90 → 极显著 |
| R3 开 → 关 | **+47.15pp** | **+42.18pp** | **+44.67pp** | t=10.44/10.52，胜 80/90、79/90 → 极显著 |

两个效应几乎**完全可加**：`44.67 - 10.37 = +34.30pp`，正好等于 B 相对 p6 的总差（+34.30pp）。
也就是说：**B 相对 p6 那 +34pp 的领先，是「关 R3（+44.7pp）」抵消掉「止损放宽到 -8.2%（-10.4pp）」之后的净额。**

### 🔴 最重要的发现：应该关 R3，但**不要**放宽止损

**C = 止损 -6.0% + R3 关** 这个组合**同时打赢了 p6 和方案 B**：

| | C vs 现用 p6 | C vs 方案 B |
|---|---:|---:|
| 收益获胜窗口 | **80 / 90** | **82 / 90** |
| 收益差（均值 / 中位） | +47.15pp / +46.20pp | +12.86pp / +7.69pp |
| 回撤更浅的窗口 | 15 / 90 | **69 / 90** |

对方案 B：C 的几何收益 **61.20% vs 50.39%**，平均回撤 **-15.06% vs -17.49%**，
**收益更高、回撤还更小**，而且是 90 个窗口里 82 个收益更高、69 个回撤更浅 —— **全面支配**。

再看尾部：**C 的最差窗口 -3.20%**（p6 -6.38%、B -6.85%），**负收益窗口 8/90**（p6 12、B 13）。
C 不只是收益最高，**尾部也是四个里最好的** —— 这正好解释了为什么 -6.0% 能赢 -8.2%：
收紧止损把「跌成深套」的样本砍掉了，而 R3 关掉后又让这些被救回来的资金重新投入了超跌反弹。

> 换句话说：**方案 B 文档里说「-8.2% 非调参所得、只是把启用时间提前」，但它从没测过 -6.0%。
> 我们 09-08 用 42 格网格 + 21 随机窗得出的 -6.0%，在这次 90 窗独立验证里同样成立，而且在 R3 关闭的新环境下依然更好。**
