## 二、原始策略（原版 hoshi）完整规格

### 2.1 一句话
**在大盘多头排列的个股中，找"连跌两天 + 企稳 + 次日收阳"的超跌反弹买点，靠高周转累积收益。**

### 2.2 数据要求
- 字段：`date, open, high, low, close, volume`（**不复权原始价**）
- 标的池**白名单**（必须用白名单，库里混着指数/ETF/债券/国债逆回购）：
  `sh600/601/603/605/688/689` + `sz000/001/002/003/300/301`
- 剔除：`ST` / `*ST` / 含`退` / 以`N`开头（上市首日）
- 每只标的**至少 66 根 K 线**才参与计算
- 回测需从开始日前推 ≥66 个交易日（MA60 预热）

### 2.3 入场信号（D 日收盘确认，D+1 开盘买入）

| # | 条件 | 参数 |
|---|---|---|
| ① | 均线多头排列 | `MA20 > MA60` |
| ② | 近 4 天内 ≥2 天下跌 | 单日跌幅 < **−2.0%** |
| ③ | D-1 为企稳日 | 锤子线 / 十字星 / 小实体（实体 < 3%），或 −2%≤跌幅≤5% |
| ④ | D 日收阳确认 | 当日涨幅 > 0 |
| ⑤ | 评分达标 | `score ≥ 8.0`（原版） |

**评分 `calc_score`（满分 10）**
```
score = 3.0
d = |总跌幅|
  10 <= d <= 25 → +2.0 ;  d > 25 → +1.5 ;  d >= 5 → +1.0
企稳形态：锤子线 +2.5 ; 十字星 +2.0 ; 其他 +1.0
下影线比 ls/rng > 0.5 → +1.0
确认日涨幅：>5% → +1.5 ; >2% → +1.0
score = min(score, 10.0)，四舍五入 1 位
```
**K 线定义**：`rng=h-l`，`body=|c-o|`，`lower=min(o,c)-l`，`upper=h-max(o,c)`
- 锤子线：`body/rng<=0.3` 且 `lower>=body*1.5` 且 `upper<=rng*0.5`
- 十字星：`body/rng < 0.15`

### 2.4 买入执行
- 买入价 = **当日 open**；最多同时持有 **10** 只
- 单笔预算 = `equity * 10%`（equity 用**成本**，不用市值）
- `shares = floor(budget/price/100)*100`
- 买入费 = `max(成交额*0.00025, 5.0)`
- **T+1**：买入当天不可卖

### 2.5 出场规则
- **模式自适应**：看最近 10 笔已完成交易均收益 < −1% → S4（每天可武装），否则 S3（第 14/15 天武装）
- **止盈**：武装后从峰值回落 1.2%（D15 后 1.0%）卖出；武装阈值 +5.2%（D15 放宽 +3.2%）
- **止损**：原版**第 15 天起**才监控（前 14 天裸奔）；跌破 −5.2% 记低点，反弹 +2.2% 卖；跌破 −8.2% 硬割
- **超时**：第 25 天开盘平
- **兜底**：第 40 天收盘强平
- **期末**：窗口内最后一根 bar 的收盘价平仓

### 2.6 门控
- **R3 回撤门控**（原版启用）：用已完成交易复利链算权益，回撤 > 25% → 停手 60 自然日，再犯升级 120 天
- **广度门控**：全市场收盘 > MA60 的占比 < **20%** → 当日不开新仓（样本 <30 不开仓）

### 2.7 费用
佣金 0.025%（最低 5 元，双边）+ 印花税 0.05%（卖出）+ 过户费 0.001%（沪市）

### 2.8 原版身份锚点（黄金基准，用于防回归）
| 窗口 | 权威收益 | 笔数 |
|---|---:|---:|
| 2011-03-01 ~ 2016-02-29 | **+153.1699%** | 380 |
| 2014-12-01 ~ 2016-11-30 | **+146.8178%** | 197 |
| 2020-10-01 ~ 2022-09-30 | **+52.7429%** | 376 |

> ⚠️ 这三条是**方案 B 口径**的锚点（评分9/启用日5/−8.2%/R3关）。修改引擎或数据后必须先对拍这三条再使用任何新结论。

## 三、最新策略 hoshi-cplus 完整规格

### 3.1 一句话
**在大盘多头排列的个股中，找"连跌两天 + 企稳 + 次日收阳"的买点，第 5 天起武装 −6.0% 硬止损，靠高周转与复利累积收益。**

### 3.2 与原版的差异（只有 3 处）
| 参数 | 原版 | **hoshi-cplus** |
|---|---|---|
| `MIN_SCORE` | 8.0 | **9.0** |
| `LOSS_HARD_START_DAY` | 15 | **5** |
| `LOSS_HARD_PCT` | −8.2% | **−6.0%** |
| `USE_R3_GATE` | True | **False** |

### 3.3 参数总表

| 类别 | 参数 | 值 |
|---|---|---|
| 信号 | MA_FAST / MA_SLOW | 20 / 60 |
| 信号 | DROP_THRESH | −2.0% |
| 信号 | MIN_BARS | 66 |
| 信号 | MIN_SCORE | **9.0** |
| 资金 | TOTAL_CAPITAL | 50 万（实盘 30 万） |
| 资金 | MAX_POSITION_R | 10% |
| 资金 | MAX_SLOTS | 10 |
| 资金 | LOT_SIZE | 100 |
| 出场 | **硬止损** | **−6.0%，第 5 天起** |
| 出场 | 止盈武装 | +5.2%（D14）/ +3.2%（D15） |
| 出场 | 移动止盈 | 峰值回落 1.2%（D14）/ 1.0%（D15） |
| 出场 | 反弹式止损 | −5.2% 破位后反弹 +2.2% 卖（D15 起） |
| 出场 | 超时 | 第 25 天开盘平 |
| 出场 | 兜底 | 第 40 天收盘强平 |
| 门控 | 广度阈值 | 20%（样本 <30 不开仓） |
| 门控 | **R3** | **关闭** |
| 模式 | S3/S4 | 近 10 笔均收益 < −1% 切 S4 |

### 3.4 出场规则优先级（命中即返回）
1. **止盈**：已武装且 `low ≤ peak×(1−trail%)` → 卖
2. **硬止损兜底**：第 5~14 天且未武装，`low ≤ 成本×(1−6%)` → 卖
3. **反弹式止损**：第 15 天起且未武装，跌破 −5.2% 后反弹 +2.2% → 卖；触 −6.0% 硬兜底
4. **超时**：第 25 天开盘 → 卖
5. **兜底强平**：第 40 天收盘 → 卖

> ⚠️ S3 模式下 `armed` **只在第 14、15 天检查**；D14 前即便峰值早已过线，`armed` 恒为 False，走硬止损。

### 3.5 实盘执行时间表（券商条件单只支持价格触发）

| 时点 | 动作 |
|---|---|
| D1 开盘 | 买入（次日开盘，9:15–9:25 集合竞价挂市价/略高限价） |
| **D2–D4** | **无止损保护（裸奔）** |
| **D5 开盘前** | ★ 挂条件止损：现价 ≤ 买入价 × 0.94 卖出全部 |
| D14 收盘后 | 若期间最高 ≥ 买入价 × 1.052 → 撤止损、改挂移动止盈（峰值回落 1.2%） |
| D15 | 若未触发止盈，止损单继续有效 |
| **D25 开盘** | ★ 撤全部条件单，市价卖出（超时平） |
| D40 | 兜底强平（正常走不到） |

### 3.6 代码位置
- 权威实现：`hoshi_cplus/`（纯标准库、零依赖，双盲重建验证通过）
  `config.py` / `signals.py` / `exits.py` / `gates.py` / `data.py` / `backtest.py` / `cli.py`
- 运行：`python -m hoshi_cplus --data scripts/hoshi_csv_2005 --preset cplus --start ... --end ...`

### 5.3 策略实现层（改代码前必读）

| # | 坑 | 现象/后果 | 处理 |
|---|---|---|---|
| 18 | **买入当天必须推进 `hold_day`** | 漏了 → 武装/硬止损/超时/强平**全部晚一天**，实测收益差 **−25%** | `COUNT_ENTRY_DAY=True`；新仓后立刻 `step_exit(..., allow_sell=False)` |
| 19 | **广度样本需 ≥66 根 K 线** | 报告曾只写"≥60 根" → 广度分母不一致 | 该标的至少 66 根才计入广度样本 |
| 20 | **广度按全局日期索引累加** | 用个股 bar 索引 → 停牌导致错位 | 用 `didx[date]` 累加 |

| 22 | **S3 武装只在 D14/D15 检查** | 即便峰值早已过武装线，D14 前 `armed` 恒 False，走硬止损 | 别以为"峰值过线就武装" |
| 23 | **`--scan DATE` 确认日错位** | `sig_by_date[d]` 用 `bars[:k]` → 确认日 = d **前一交易日**；`build_plan` 又把 exec_day 写成 signal_day+1 → 一天错位 | 实盘必须用 **live 模式**（确认日 = 最后一根 bar，执行日 = 下一交易日） |
| 24 | **scan 不自动剔除涨停票** | 确认日涨停的票仍进候选 | 人工/脚本剔除：涨幅 ≈ +10%/+20% **且** 收≈最高 |
