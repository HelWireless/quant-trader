## 三、根因：前 14 天没有止损保护（策略设计如此，非 bug）

单笔亏损动辄 -33%、-41%、-56%，远超策略声称的 -8.2% 硬止损。
查 `hoshi_backtest_csv.py:336`：

```python
if hd >= 15 and not armed:      # ← 止损只在持有第 15 天后才启动
    if not pos['loss_armed'] and low <= entry * (1 + LOSS_ARM_PCT / 100.0):
        ...
    if pos['trough'] <= entry * (1 + LOSS_HARD_PCT / 100.0):
        return entry * (1 + LOSS_HARD_PCT / 100.0), '止损(硬止损)'
```

对照 `hoshi_final_strategy.md` 第 59-61 行**原文**：

> 两者共用的止损/死线/强平规则：
> - **止损（第15天起监控，只针对未武装止盈的仓位）**：最低价跌破 **-5.2%** 先记录低点，
>   等反弹 **+2.2%** 后止损卖出；反弹前继续下探到 **-8.2%** 直接硬止损。

**即：策略设计上就是前 14 天完全不止损。** 回测器忠实实现了文档，不是移植错误。

灾难性组合 = ① 7/1 一次性买满 10 只（无时间分散）+ ② 前 14 天无止损
+ ③ 遭遇 7 月连续暴跌（单票 -20%、-12%、-11% 连跌）。

**单票实例（300522）**：7/8 收 24.10 → 7/30 收 10.67，一个月 **-56%**。
中间 7/9 单日 -20%、7/13 -11.3%、7/20 -12.0%。若第 1 天就有 -8.2% 硬止损，
亏损应控制在 -20% 以内（跳空跌幅），而非 -56%。

## 五、建议（未实施，待拍板）

1. **加"全程硬止损"**：不论第几天，跌破 -8.2%（或更紧的 -10%）立即市价止损。
   这是本次暴露的最大敞口。建议先回测对比"全程止损 vs 第15天才止损"。
2. **单日建仓数量上限**：7/1 一次性买满 10 只，风险过度集中。
   可限制每日最多开 3~4 仓，分散时间风险。
3. **R3 冷却期复盘**：60 天冷却在短回测区间内等于"永久停手"，
   长周期（策略文档称 11.5 年）里是合理的，但需确认是否符合预期。
